# Homebrew tap for EnvRune

[EnvRune](https://github.com/YagoLagrottiBracco/envrune) keeps environment
variables encrypted and gives them to the commands that need them.

```sh
brew install --cask yagolagrottibracco/tap/envrune
```

`Casks/envrune.rb` is written by EnvRune's release workflow; changes made
here are replaced by the next release.
